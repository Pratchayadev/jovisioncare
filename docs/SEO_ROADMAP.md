## 1. ผลตรวจไฟล์เดิม (สรุป)

ไฟล์เดิมวางหลักการได้ดี: ห้ามแต่งข้อมูล ห้ามสร้างหน้าบางเพื่อดักคำค้น ทำ Google Business Profile แยกสาขา วัดผลด้วยข้อมูลจริง — **หลักการเหล่านี้เก็บไว้ทั้งหมด** (ข้อ 6)
ส่วนที่ต้องตัดหรือปรับ เพราะทำไปแล้ว หรือจะทำให้เว็บแย่งอันดับกันเอง:

| หัวข้อในไฟล์เดิม | ผล | เหตุผล |
|---|---|---|
| หน้าสาขา `/udon-thani` `/nong-khai` (สัปดาห์ 1) | ✅ ทำแล้ว | มี H1/Title/Meta เฉพาะสาขา ที่อยู่ แผนที่ เวลา โทร รูปร้านจริง รีวิว และ Schema `Optician` |
| Technical SEO checklist (ข้อ 8) | ✅ ทำแล้วเกือบทั้งหมด | ดูรายการในข้อ 8 ของไฟล์นี้ — เหลือแค่ส่ง Sitemap ใน Search Console |
| Tracking การโทร/LINE/ปุ่มติดต่อ | ✅ ทำแล้ว | GA4 event `contact_click` แยกช่องทาง/สาขา/สินค้า (LINE จะนับเมื่อเปิดลิงก์ LINE) |
| `/articles/` หน้ารวมบทความ | ✅ ทำแล้ว | พร้อมระบบเขียนบทความในหลังบ้าน |
| ชื่อแบรนด์ `JOVISIONCARE` | ✏️ ปรับ | เว็บ, Schema และป้ายร้านใช้ **J.O. Vision Care** — ต้องใช้ชื่อเดียวกันทุกที่ (เว็บ, Google Business Profile, Facebook) ไม่งั้น Google อาจมองเป็นคนละธุรกิจ |
| Title/H1 หน้าแรกที่เสนอ (“JOVISIONCARE ร้านแว่นตา ตัดแว่นและวัดสายตา”) | ❌ ไม่ใช้ | ของเดิมดีกว่า: มีชื่อจังหวัดทั้งสองในทั้ง Title และ H1 ซึ่งเป็นคำค้นหลัก การตัดออกจะเสียความเกี่ยวข้องเชิงพื้นที่ |
| URL `/sunglasses/` `/eyewear-brands/` `/promotions/` | ❌ ไม่สร้างใหม่ | มีหน้าเดียวกันอยู่แล้ว: `/category/sunglasses`, `/category/promotion`, `/brand/...` — สร้างซ้ำจะแย่งอันดับกันเอง ให้เติมเนื้อหาในหน้าเดิมแทน (หลังบ้านรองรับแล้ว) และเพิ่มหน้ารวมแบรนด์ `/brands` |
| `/prices/` แยกจาก `/promotions/` | ❌ ตัด (ตอนนี้) | ยังไม่มีราคาที่เผยแพร่ได้ หน้าจะบาง — เมื่อมีข้อมูลราคา ให้ใส่ในหน้าบริการ/หน้าโปรโมชันแทน |
| หน้าเลนส์โปรเกรสซีฟ **และ** บทความ “โปรเกรสซีฟคืออะไร” | ✏️ รวมเป็นหน้าเดียว | สองหน้าตอบคำค้นเดียวกัน = แย่งอันดับกันเอง ใช้หน้าบริการหน้าเดียวที่ครบ บทความไปเขียนเรื่องที่ต่างจริง (เช่น เปรียบเทียบเลนส์ชั้นเดียว vs โปรเกรสซีฟ) แล้วลิงก์มา |
| บทความ “คู่มือการเดินทางไปแต่ละสาขา” (สัปดาห์ 8) | ✏️ ย้ายไปหน้าสาขา | ถ้าแยกเป็นบทความจะแย่งกับหน้าสาขา — เพิ่มส่วน “การเดินทาง / จุดสังเกต / ที่จอดรถ” ในหน้าสาขาแทน |
| URL มี `/` ปิดท้าย | ✏️ ไม่ใช้ | เว็บใช้ URL ไม่มี `/` ท้าย มี canonical ถูกต้องแล้ว อย่าเปลี่ยน |
| ตาราง Keyword ที่ต้องกรอก Search Volume ตั้งแต่ต้น | ✏️ เลื่อน | ร้านท้องถิ่นคำค้นปริมาณต่ำ Keyword Planner ให้แค่ช่วงกว้าง ๆ ใช้ข้อมูลจริงจาก Search Console หลังเก็บ 4–6 สัปดาห์จะแม่นกว่า |
| FAQ | ✏️ ปรับความคาดหวัง | Google แสดง FAQ แบบพิเศษในผลค้นหาเฉพาะเว็บราชการ/สุขภาพแล้ว ทำ FAQ เพื่อช่วยผู้อ่านและคำค้นแบบคำถาม ไม่ใช่เพื่อ rich result |

**ที่ไฟล์เดิมยังขาด** (เพิ่มไว้ในแผนนี้): รีวิว Google เป็นงานต่อเนื่อง, Bing Webmaster Tools, ความสม่ำเสมอของข้อมูลร้านบน Facebook/ไดเรกทอรี, Google Merchant Center (เมื่อมีราคา), ลูกค้าจากลาวที่สาขาหนองคาย, แบนเนอร์คุกกี้ PDPA

**หลักการ**
- หนึ่งคำค้นหลัก = หนึ่งหน้า ถ้าจะเขียนเรื่องใกล้กัน ให้เขียนมุมที่ต่างจริงแล้วลิงก์ไปหน้าหลัก
- ไม่สร้างหน้าแยกตามอำเภอ/จังหวัดที่ไม่มีสาขา (doorway page)
- หน้าบริการแต่ละหน้าลิงก์ไปทั้งสองสาขา หน้าสาขาลิงก์ไปหน้าบริการที่สาขานั้นมีจริง
- ชื่อจังหวัดใส่ในหน้าบริการเท่าที่เป็นธรรมชาติ (“มีบริการที่สาขาอุดรธานีและหนองคาย”) ไม่ต้องสร้างหน้า “โปรเกรสซีฟอุดร” / “โปรเกรสซีฟหนองคาย” แยก

### Brief สำหรับแต่ละหน้า/บทความ
1. เจตนาการค้นหา + ผู้อ่านเป้าหมาย
2. คำค้นหลัก 1 คำ + คำรอง 2–4 คำ (ตรวจว่าไม่มีหน้าเดิมรองรับคำนี้อยู่แล้ว)
3. Title (≤ 60 ตัวอักษร), Meta description (70–160), H1
4. โครงหัวข้อ H2/H3 ที่ตอบคำถามตามลำดับ
5. เนื้อหาภาษาไทยเป็นธรรมชาติ ไม่ยัดคำค้น บทความ 1,500 ตัวอักษรขึ้นไปเมื่อเรื่องต้องการ
6. ลิงก์ภายในอย่างน้อย 2 ลิงก์ (หน้าบริการ/หมวด/สาขา)
7. รูปจริงของร้านหรือสินค้า พร้อมคำอธิบายรูป (alt)
8. CTA: เลือกสาขา / โทร / LINE — ใช้ลิงก์จริงเท่านั้น
9. แหล่งอ้างอิง (เรื่องสุขภาพ/เทคนิค)
10. FAQ เฉพาะเมื่อตอบคำถามจริง
11. รายการข้อเท็จจริงที่ร้านต้องตรวจก่อนเผยแพร่

**ในหลังบ้าน:** กล่อง “ตรวจ SEO” ต้องได้ ≥ 80 ก่อนกดเผยแพร่ · slug ภาษาอังกฤษสั้น ๆ เช่น `progressive-vs-single-vision`

## 6. กฎที่ต้องทำตาม (สำหรับทีมและ AI)

- ห้ามรับประกันอันดับ · ห้ามแต่งตัวเลข Search Volume / Keyword Difficulty
- ห้ามแต่ง ที่อยู่ เบอร์ เวลา ราคา ยี่ห้อ รีวิว บริการ หรือคุณสมบัติสินค้า — ไม่รู้ให้เขียน `ยังไม่ทราบ` แล้วถามร้าน
- ข้อมูลแต่ละสาขาใช้ตามจริง ไม่นำของสาขาหนึ่งไปอ้างอีกสาขา
- ไม่สร้างหน้าบาง/หน้าซ้ำเพื่อดักคำค้น ไม่ก๊อปเนื้อหาเว็บอื่น ไม่ยัดคำค้น
- ไม่ใส่ดาวรีวิวของร้านเองใน Schema · ไม่ซื้อรีวิว
- โปรโมชันต้องมีเงื่อนไขและวันหมดอายุ (ถ้ามี) และอัปเดตเมื่อหมด
- แยก ข้อเท็จจริง / สมมติฐาน / ข้อมูลที่ต้องยืนยัน ให้ชัดในทุก brief
- ก่อนเปลี่ยน URL ของหน้าที่มีอยู่ ให้ตรวจ Search Console ก่อน (ระบบทำ redirect 301 ให้อัตโนมัติเมื่อเปลี่ยน slug ในหลังบ้าน)

## 8. สิ่งที่ทำบนเว็บแล้ว (อ้างอิง — ไม่ต้องทำซ้ำ)
